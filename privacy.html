Política de Privacidade

Esta política se aplica ao Dentro do Óbvio Publicador, ferramenta interna do canal Dentro do Óbvio, de uso exclusivo do dono do canal.

Dados acessados

Quando o dono do canal autoriza o acesso, o app acessa apenas dados das contas dele no YouTube, Instagram e TikTok:

  • YouTube: informações do canal autorizado, envio de vídeos para esse canal e estatísticas (YouTube Analytics) desse canal;
  • Instagram: perfil básico, estatísticas, lista de vídeos e publicação de vídeos na conta autorizada;
  • TikTok: perfil básico, estatísticas, lista de vídeos e envio/publicação de vídeos na conta autorizada.

O app não coleta dados de outros usuários.

Como os dados são usados

Os dados são usados apenas para publicar e medir os vídeos das próprias contas do dono do canal. Não há outro uso.

Compartilhamento e armazenamento

Os dados não são vendidos nem compartilhados com terceiros. Eles ficam guardados em um servidor privado do dono do canal.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento nas configurações da própria conta de cada plataforma. No caso do Google/YouTube, em https://myaccount.google.com/permissions.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
